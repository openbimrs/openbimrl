Status: namespace reserved; implementation not authorized or started.

## Established boundary

This package owns the minimal `PACKAGE_STATUS` item. It has no runtime
dependencies and makes no parser, language, schema, validation, or conformance
claim.

## Preconditions for any implementation proposal

- [ ] Identify an authoritative, citable specification and its provenance.
- [ ] Establish lawful access and redistribution rules for every proposed
      fixture or artifact.
- [ ] Define scope without suggesting standards-body affiliation or endorsement.
- [ ] Add executable evidence and revise all capability documentation.
- [ ] Preserve a lossless and explicit package migration path from the reserved
      status API.

These are unclaimed future preconditions, not a roadmap or representation that
an openBIMRL technology exists.
